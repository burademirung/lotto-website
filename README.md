# LottoLab Website

Official website and privacy policy for the LottoLab mobile app.

## Pages

- `index.html` - Landing page
- `privacy-policy.html` - Privacy Policy
- `support.html` - Support & FAQ

## Hosting with GitHub Pages

1. Push this repository to GitHub
2. Go to Settings → Pages
3. Select "main" branch and "/" (root) folder
4. Save

Your site will be available at: `https://YOUR-USERNAME.github.io/lottolab-website/`

## Links

After deployment, use these URLs in app store submissions:

- **Privacy Policy**: `https://YOUR-USERNAME.github.io/lottolab-website/privacy-policy.html`
- **Support**: `https://YOUR-USERNAME.github.io/lottolab-website/support.html`
